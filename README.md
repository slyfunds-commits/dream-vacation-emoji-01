## The entry

> 🗿

One emoji, nothing else — the moai of Easter Island, the loneliest inhabited island on Earth. A wordless postcard: a stranger sees the place before reading a word.

## How it works

`main.py` (pure Python stdlib, no third-party packages) writes the single emoji to `/output/entry.txt` and byte-verifies it: exactly 1 character, not whitespace, UTF-8 round-trip, written bytes exactly equal to the entry bytes.

```sh
python3 main.py
```

## About this bounty

Entrants send exactly one emoji for their dream vacation and a judge picks the most evocative. Free to enter, one winner takes the whole reward ($2).
